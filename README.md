# Phishing Website Detection using Machine Learning & Web Scraping

## 📌 Project Overview
This project is developed for the CIPAT requirement. It focuses on detecting malicious/phishing URLs using Web Scraping, Exploratory Data Analysis (EDA), Hypothesis Testing, and Machine Learning models (Random Forest & Decision Tree).

## 🛠️ Tech Stack & Libraries Used
- **Language:** Python
- **Web Scraping:** BeautifulSoup, Requests
- **Data Handling:** Pandas, NumPy
- **Visualization & Hypothesis Testing:** Matplotlib, Seaborn, SciPy (t-Test)
- **Machine Learning:** Scikit-Learn (RandomForestClassifier, DecisionTreeClassifier)

## 📊 Results & Model Accuracy
- **Dataset Size:** 87,209 URL records
- **Random Forest Accuracy:** 96.93%
- **Hypothesis Testing:** Rejected Null Hypothesis ($p$-value = 0.0), confirming URL length is statistically significant.

## 🚀 How to Run
1. Open `Phishing_Detection_CIPAT.ipynb` in Jupyter Notebook.
2. Go to menu: **Kernel -> Restart & Run All**.
